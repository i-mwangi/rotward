# Product Overview

## HexScroll
An offline-first Android app that blocks short-form video doomscrolling (Instagram Reels, YouTube Shorts, TikTok, Facebook Reels) using two layered mechanisms.

### Blocking Engine
An AccessibilityService monitors foreground short-form video surfaces and enforces one of four modes: Block All, Daily Limit, Interval Timer, Nothing Selected.

### Learning Gate
When enabled, intercepts a blocked feed with an offline MCQ from 2-5 user-selected topics. Pass grants a 5-min grace window. Fail triggers the Haunting Screen and a 3-min cooldown.

### Target Users
People who want to reduce doomscrolling. The quiz mechanic makes breaking the habit feel consequential.
